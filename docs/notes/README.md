# Notes Folder / Notes 目录说明

`docs/notes/` is for temporary working notes, personal checklists, draft planning files, and other non-canonical documents.

`docs/notes/` 用于存放临时工作笔记、个人清单、草稿规划文件以及其他非正式定稿文档。

Use this folder for items such as:

适合放在这里的内容包括：

- daily task notes / 每日任务笔记
- rough drafts / 草稿
- local workflow reminders / 本地流程提醒
- Codex usage notes / Codex 使用说明或心得

Do not keep this kind of material in the repository root unless there is a strong reason.

除非有明确理由，否则不要把这类材料散落在仓库根目录。
