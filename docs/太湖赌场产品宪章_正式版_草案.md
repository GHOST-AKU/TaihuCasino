# 太湖赌场产品宪章 v1.0（正式版草案）

状态：草案  
日期：2026-04-06  
适用范围：TaihuCasino 全团队（产品、设计、研发、美术、运营、数据、商业化）

## 0. 宪章目的

本宪章用于回答四个核心问题：

1. 我们是谁，要做一个什么样的产品。
2. 我们做什么，不做什么，边界在哪里。
3. 什么样的决策符合太湖赌场的价值观。
4. 各团队如何在同一套原则下协作、判断与取舍。

本宪章是 TaihuCasino 的最高产品原则文件。若局部方案与本宪章冲突，以本宪章为准。

## 1. 使命

我们不是在贩卖运气，而是在设计体验。

太湖赌场不是一个用刺激和焦虑驱动停留的赌场题材产品，而是一款以优雅陪伴、数学认知、休闲博弈为核心的独立游戏。

我们提供的不是输赢本身，而是节奏、氛围、心理预期与陪伴感。  
想玩时，玩家能获得有节奏感和策略感的轻博弈体验；  
不玩时，玩家也能获得安静、稳定、长期的陪伴体验。

## 2. 愿景

打造“赌场题材中的异类精品”：

- 不是最刺激的
- 不是最喧闹的
- 不是最擅长短期收割的
- 而是最有质感、最可持续、最有记忆点的

我们希望太湖赌场成为这一题材里兼具审美价值、认知价值与长期信任的作品。

## 3. 产品定位

太湖赌场是一款以虚拟代币为核心的赌场题材休闲游戏，而非真钱赌博产品。

它由三层体验共同构成：

- 玩法层：轻博弈、快反馈、可复玩
- 认知层：概率、期望、波动等数学内容可被理解和感知
- 情绪层：太湖意境下的陪伴、停留与放松

它面向的是：

- 喜欢概率玩法，但厌倦高噪音氪金体验的玩家
- 对策略、数学、理性叙事有兴趣的成年用户
- 寻求轻陪伴、轻放置体验的休闲玩家

## 4. 我们是什么 / 不是什么

我们是：

- 一款以体验设计为核心的产品
- 一套带有叙事、情绪与认知结构的系统
- 一种克制的娱乐机制

我们不是什么：

- 不是线上真钱赌场
- 不提供任何提现、兑奖或现实价值兑换
- 不做纯概率刺激机器
- 不做靠充值驱动的强刺激收割产品
- 不做高噪音、强打断、强焦虑的泛博彩 UI 产品
- 不做以付费压制免费玩家的 P2W 结构

## 5. 核心价值观

### 5.1 克制优先于刺激

我们不依赖噪音、爆闪、催促和“差一点就中”的强刺激机制驱动用户停留。

### 5.2 可解释性优先于神秘化

结果可以被理解，机制可以被说明，概率不应被神化为不可触碰的“运气”。

### 5.3 陪伴优先于操控

即便不下注，玩家也应感到值得停留；产品不应通过焦虑和沉没成本强迫用户继续。

### 5.4 长期关系优先于短期转化

我们优先追求留存、口碑与信任，而不是依靠短期榨取换取收入峰值。

### 5.5 体验优先于收益

商业化必须服务于整体体验，不能以破坏节奏、破坏信任为代价换取短期收益。

## 6. 设计原则

1. 10 秒内进入核心体验。
2. 失败后可恢复，不让一次挫败切断长期体验。
3. 信息分层，默认轻量，深度内容由玩家主动展开。
4. 每一次付费都应买得到明确价值。
5. 每一次广告都应是公平交换，而不是强制惩罚。
6. 页面、反馈、文案都应可呼吸，不过载、不喧哗。
7. 所有概率相关表述都必须可审校、可验证。

## 7. 产品层结构

### 7.1 玩法层（Game Layer）

提供基础的可玩性和复玩性，但不过度强调输赢刺激。

### 7.2 数学层（Math Layer）

通过概率、期望、波动和回报曲线构建节奏，让玩家理解结果，而不是被结果操控。

### 7.3 节奏层（Pacing Layer）

通过反馈频率、冷却、局间节奏和场景切换管理玩家心理节奏，避免持续高压。

### 7.4 陪伴层（Companion Layer）

通过环境、角色、文案和非下注内容，让玩家在不下注时也有停留价值。

## 8. 核心系统边界

### 8.1 必做（Must Have）

- 2 到 3 款核心游戏，统一账户与代币体系
- 数学解释层，包含轻量旁白与深度学院模式
- 非下注状态可停留的挂机陪伴系统
- 激励广告与小额 IAP
- 基础埋点、远程配置与稳定性保障

### 8.2 后做（Should Later）

- 赛季活动与主题收藏
- 个性化数学课程与进阶挑战
- 跨端账号与云同步增强
- 更复杂的社交与展示系统

## 9. 商业化原则

### 9.1 经济原则

- 虚拟代币不可提现，不可兑换现实货币
- 控制破产挫败，确保免费玩家也可持续游玩
- 成长不只依赖下注币，也应包含学习、审美和陪伴维度

### 9.2 广告原则

- 激励广告优先，插屏广告克制且低频
- 触发时机必须合理、可理解、可选择
- 单会话广告频次必须有明确上限
- 禁止误触式广告设计

### 9.3 IAP 原则

- 售卖的是便利、审美与陪伴价值，不是胜利保证
- 商品结构必须简洁、可理解、可比较
- 禁止通过焦虑制造逼付费

## 10. 用户体验目标

我们希望玩家获得以下感受：

- 不会感到被榨取
- 可以随时退出而没有焦虑
- 记住的是氛围、节奏与气质，而不只是输赢
- 愿意回来，不是因为沉没成本，而是因为舒适、信任和习惯

## 11. 成功定义

### 11.1 北极星指标

每活跃玩家的有价值时长：

有价值时长 = 游玩时长 + 学习时长 + 陪伴时长  
不计入被动广告时长

### 11.2 核心业务指标

- D1 / D7 / D30 留存
- 平均有效会话时长
- 数学模块开启率与完成率
- 非下注状态停留时长
- 激励广告完成率
- IAP 转化率与复购率

### 11.3 质量底线指标

- 崩溃率小于 1%
- 关键流程严重卡顿率小于 2%
- 广告强打断相关投诉率持续下降
- 新手引导完成率大于 80%

## 12. 伦理与边界

以下原则不得突破：

- 不设计成瘾陷阱
- 不利用用户认知偏差进行剥削
- 不制造现实收益幻想
- 不夸大快赢概率
- 不通过极端挫败制造消费压力
- 不将用户引导至真钱赌博语境
- 未成年人保护与广告合规必须前置

## 13. Feature Gate

任何新功能在进入开发前，必须同时回答以下问题：

1. 是否提升了有价值时长，而不是只增加使用时长？
2. 是否符合太湖赌场的优雅气质？
3. 是否增强了可解释性、陪伴感或核心体验？
4. 是否不会破坏经济平衡、玩家信任和可退出性？

若任一答案为“否”，该功能不得进入正式开发。

## 14. 优先级原则

- P0：核心循环、基础玩法、基础反馈、数学轻量解释、低余额复归、稳定性、基础商业化
- P1：学院模式、太湖雅集、体验增强、远程配置、AB 测试
- P2：扩展玩法、赛季化内容、复杂社交与长期收藏系统

## 15. 版本路线

- v1.0：最小可行体验，完成核心玩法、轻量数学解释、基础商业化与基础陪伴
- v1.1：补强学院模式、每日挑战与活动节奏
- v1.2：补强完整的太湖雅集挂机系统、成长线与收藏系统

## 16. 团队协作契约

- 产品、设计、研发、美术、运营、数据共享同一价值观
- 任何人都可以对“体验退化”提出质疑
- 需求评审必须进行宪章对齐检查
- 违背宪章的功能可进入冻结复审
- 以长期质量、长期信任和长期关系作为最终评判标准

## 17. 宪章维护机制

- 每月一次宪章回顾
- 新版本立项必须附带宪章符合性评估
- 若需修订宪章，必须说明变更原因、影响范围与风险

## 18. 宪章口号

在太湖边，我们不贩卖运气；我们设计可被理解的随机，与可被感受的陪伴。
