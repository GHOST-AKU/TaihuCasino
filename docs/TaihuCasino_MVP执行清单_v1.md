# TaihuCasino MVP 执行清单 v1

日期：2026-04-09

本清单服务于《TaihuCasino 两人团队开发计划 v1》，用于把路线图转成近期可执行的检查项。

## 1. 项目收敛

- 选定 MVP 主线页面
- 标记非主线页面
- 统一首页入口表达
- 统一会员入口位置
- 梳理公共脚本与页面脚本边界

## 2. 账户与会员

- Auth0 前端配置可切换环境
- 登录可用
- 登出可用
- 回调可用
- 刷新后会话恢复可用
- 玩法页受保护访问可用

## 3. Supabase 数据闭环

- 建立用户资料结构
- 建立钱包结构
- 建立玩法进度结构
- 建立购买记录结构
- 建立广告奖励事件结构
- 建立会话事件结构

## 4. 四玩法接入

- 百家乐接统一钱包
- 轮盘接统一钱包
- 骰子接统一钱包
- 21点接统一钱包
- 四玩法都可保存基础进度
- 四玩法都可回到大厅

## 5. 变现闭环

- 激励广告奖励路径
- 失败恢复广告路径
- 商品列表
- 购买到账
- 购买失败处理
- 钱包统一入账与回滚

## 6. 实验准备

- 记录注册数
- 记录登录成功率
- 记录玩法开局率
- 记录每局完成率
- 记录广告完成率
- 记录首购率
- 记录恢复存档成功率

## 7. 验收口径

满足以下条件才算 MVP 可实验：

- 用户可以注册、登录、登出
- 统一钱包在四玩法之间生效
- 核心资料和进度可以恢复
- 广告与 IAP 至少各有一条真实路径可测
- 关键行为事件可追踪
- 页面体验未违反产品宪章中的边界与原则
