# TaihuCasino 技术栈决议

## 决议

从 `2026-04-14` 起，TaihuCasino 的正式前端技术栈确定为：

- `React`
- `Next.js`
- `TypeScript`

## 这次决议实际落地了什么

这不是只停留在文档里的决定，而是已经落实到仓库结构：

- 原 `vercel ver/` 中的 Next.js 应用已吸收到仓库正式根结构
- 正式页面入口改为根目录的 `app/`
- 正式组件、hooks、工具函数和静态资源也已进入根目录工程
- 原来的静态 `home*` 与 `index` 已移入 `prototypes/`
- 现有承载游戏内容的 `pages/` 与 `assets/` 保留在根目录，作为迁移过渡层

## 为什么这么定

相比继续以多个独立 HTML 原型推进，`React + Next.js` 更适合当前项目的后续演进：

- 更容易组件化与复用
- 更适合承接复杂交互和状态
- 更便于后续路由扩展和页面整合
- 更适合长期维护和工程化协作

## 当前执行规则

1. 新功能默认在根目录 Next.js 工程中开发
2. 原型页面仅作为参考，不再作为主线继续堆功能
3. 现有游戏页允许继续在 `pages/` 中维护，但目标仍是逐步迁移到 React / Next.js
4. 如需吸收旧方案内容，优先迁移为 React 页面或组件
