太湖赌场产品宪章 v1.1（融合版）

一、使命（Mission）
我们不是在贩卖运气，而是在设计体验。

在一个被概率、刺激与成瘾机制统治的传统赌场叙事中，我们选择成为一个异类：
一个更克制、更精致、更有人味的“赌场”。

我们提供的不是输赢本身，而是：
节奏、氛围、心理预期与陪伴感。

二、愿景（Vision）
打造“赌场题材中的异类精品”：
不是最刺激、不是最赚钱，而是最有质感、最可持续、最有记忆点的产品。

三、我们是什么 / 不是什么
我们是：
- 一种体验设计产品
- 一种带有叙事与情绪结构的系统
- 一种克制的娱乐机制

我们不是什么：
- 不做纯概率刺激机器
- 不做短期爆收割型产品
- 不做噪音型、强干预型赌场

四、核心设计原则
1. 克制优先于刺激
2. 体验优先于收益
3. 节奏优先于频率
4. 陪伴优先于操控
5. 长期关系优先于短期转化

五、产品层结构
1. 玩法层（Game Layer）
提供基础的“可玩性”，但不过度强调输赢刺激。

2. 数学层（Math Layer）
通过概率与回报曲线控制节奏，而不是制造极端波动。

3. 节奏层（Pacing Layer）
通过时间、冷却、反馈控制用户的心理节奏。

4. 陪伴层（Companion Layer）
通过角色、环境与交互建立情感连接。

六、用户体验目标
- 用户不会感到被“榨取”
- 用户可以随时退出而没有焦虑
- 用户会记住氛围，而不是输赢
- 用户愿意回来，不是因为沉没成本，而是因为舒适

七、商业化原则
- 收入来自长期关系，而非短期刺激
- 控制付费频率与强度
- 避免利用脆弱心理进行转化

八、Feature Gate（功能准入机制）
任何新功能必须回答：
1. 是否破坏节奏？
2. 是否增加焦虑？
3. 是否提升体验而非刺激？

若答案不成立，则不进入开发。

九、优先级（P0 / P1 / P2）
P0：核心体验（节奏、基础玩法、基础反馈）
P1：体验增强（视觉、音效、轻叙事）
P2：扩展功能（社交、复杂系统）

十、伦理与边界
- 不设计成瘾陷阱
- 不利用用户认知偏差进行剥削
- 保持可退出性与透明度

十一、版本路线
v1：最小可行体验（MVP）
v2：体验打磨与稳定
v3：扩展内容与长期系统

十二、协作契约
- 产品、设计、研发共享同一价值观
- 任何人可以对“体验退化”提出质疑
- 以长期质量作为唯一评判标准

十三、下一步
进入《MVP范围与验收标准》定义与拆解阶段。
