# 太湖赌场后续文档目录 v1.0

日期：2026-04-06  
适用对象：TaihuCasino 5-8 人团队

本目录用于承接《太湖赌场产品宪章 v1.0》。  
宪章负责定义方向、边界与判断原则；后续文档负责把这些原则继续转化为可执行、可验证、可协作的工作材料。

## 1. 《TaihuCasino MVP 范围与验收标准 v1.0》

优先级：P0

目标：把宪章中的“必做范围”和“优先级原则”转成首个版本的功能边界、非功能要求、验收口径与上线闸门。

## 2. 《TaihuCasino 体验风格规范 v1.0》

优先级：P0

目标：约束视觉、交互、声音与文案的一致性，确保“高端克制、太湖气质、低噪音节奏”可以在实际产出中被执行。

## 3. 《TaihuCasino 商业化约束细则 v1.0》

优先级：P1

目标：细化广告、IAP、破产恢复、免费玩家可持续游玩等规则，避免商业化在实现过程中偏离宪章。

## 4. 《TaihuCasino 埋点与指标定义 v1.0》

优先级：P1

目标：将“有价值时长”、留存、数学模块参与率、非下注停留时长等指标定义为统一的数据口径，用于后续分析与复盘。

## 5. 《TaihuCasino 功能提案检查表 v1.0》

优先级：P1

目标：把 Feature Gate 和宪章对齐检查变成一个轻量模板，供产品、设计、研发在新功能评审时直接使用。

## 6. 使用原则

- 宪章优先于后续文档
- 后续文档不得修改宪章边界，只能细化执行口径
- 若后续文档与宪章冲突，应先修订文档，不应绕过宪章
- 当团队规模扩大或系统复杂度显著提升时，再考虑增加新的专项文档
